## 2. 🛠️ 典型 Agent 交互与修复工作流模式

根据对 2,280 条 Golden 轨迹的聚类分析，高成功率轨迹均遵循以下标准 SWE 交互模式：
1. **定位阶段 (`search`)**：Agent 根据 Prompt 中的 Issue 报错栈，精准检索目标函数或类名，通常消耗 2~5 次搜索定位到具体文件。
2. **代码审查 (`file_editor`)**：查看目标函数上下文（通常使用 `view_file` / `file_editor:view`），确认 Bug 诱因。
3. **补丁编写 (`file_editor:edit`)**：做出精准且符合代码规范的最小修改（Diff 通常在 5~30 行以内，避免误伤现有逻辑）。
4. **测试验证 (`execute_bash`)**：调用 `pytest tests/...` 或 `python -m unittest` 运行回归测试，验证修复有效性。
5. **提交完成 (`finish`)**：通过测试后调用 finish 退出，获取 `reward = 1.0`。
